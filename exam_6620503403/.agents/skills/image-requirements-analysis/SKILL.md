# When to use
Use for photographed, scanned, or handwritten papers.
# Workflow
1. Inspect the full page. 2. Zoom into headings, labels, axes, and notes. 3. Transcribe only readable text. 4. Mark uncertain text with location and alternatives. 5. Ask for a clearer crop only when uncertainty changes implementation.
# Technical rules
Do not infer hidden columns or chart values. Cross-check repeated labels and units.
# Example
Record “Y-axis appears to be revenue (THB), confidence medium” rather than asserting it.
# Validation checklist
All page regions inspected; units/legends/filter labels captured; uncertainty list exists.
# Common mistakes
Treating OCR as authoritative, ignoring handwritten corrections, or guessing blurred digits.
